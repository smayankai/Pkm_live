# Pkm Live

A platform for live Pokémon tournament tracking and management.

## Features

- Tournament creation and management
- Live match tracking
- Results grouped by rounds
- Player profiles
- Tournament standings
- Supabase-powered backend

## Tech Stack

- Next.js
- React
- TypeScript
- Supabase
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```
